## Purpose of This Repository

This repository is a research record maintained by NMA Consulting Group documenting the due diligence performed before putting forward the Crypto Trust Standard (CTS) framework.

NMA's starting point was a research question, not a product: *does a bundled, four-layer crypto safety framework already exist that any exchange can adopt as a listing benchmark?* This repository records how that question was investigated and what was found.

The record serves three purposes:

1. To show that NMA researched the existing ecosystem thoroughly before proposing anything
2. To document what tools and frameworks were found — and what was not found
3. To ensure that all prior art identified is explicitly acknowledged in NMA's public-facing CTS documentation

This repository is **not** a legal opinion and is **not** a claim of exclusivity. NMA is an advisory firm that identified a gap in the existing ecosystem and proposed a framework to address it. This record documents the research behind that proposal.

---

## What Was Searched

Research covered the following categories:

- Published cryptocurrency safety and security standards
- Exchange listing requirement frameworks
- Token scam-prevention tools and platforms (liquidity locking, audit firms, anti-whale mechanisms, identity protocols)
- Regulatory and policy frameworks (SEC, IOSCO, MiCA, CFTC publications)
- Academic literature and white papers on crypto fraud prevention
- GitHub repositories for open-source crypto safety frameworks
- Industry consortium publications (CryptoConsortium, CCSS, etc.)
- Web search results across multiple query formulations targeting the specific CTS concept

---

## Key Finding — Summary

**No framework was found that combines all four of the following into a single named, bundled framework:**

1. Liquidity locking with minimum duration and release rate requirements
2. Anti-whale enforcement with wallet caps and daily sell limits governed by supermajority vote
3. On-chain verification specifying live blockchain sourcing for all balance displays
4. Cryptographic endorsement registry with zk-proof KYC and wallet-signed promotional content

The individual components exist as separate, voluntary, uncoordinated tools. No bundled framework combining all four was found. That gap is what prompted NMA to put forward the CTS framework as a proposed solution — one that any exchange can choose to adopt and any compliant project can build toward.
